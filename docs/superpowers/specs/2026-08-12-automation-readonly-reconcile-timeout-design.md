# 自动认领只读刷新与超时修复设计

> 历史设计记录，非当前操作手册。下文的状态名、命令、实施步骤、测试结果及‘当前’均属于当时的设计或记录，不代表本版本已经实现或仍然适用。不要按其中的提交、测试优先或重启步骤直接执行；现行流程以 [README](../../../README.md)、[项目规则](../../../AGENTS.md) 和 [Skill](../../../skills/code-loop-board/SKILL.md) 为准。

## 目标

自动认领设置的状态刷新只读取 Codex 自动化，不得把浏览器中缓存的开关状态重新应用；用户修改设置时允许宿主链路最多等待 60 秒，以覆盖多槽位串行更新耗时。

## 操作路径

1. 用户打开自动认领面板或切换项目。
2. `web/src/App.tsx` 通过 `list` 请求读取当前自动化与已保存策略。
3. 用户修改开关或其他设置时，才发送 `apply-policy`。
4. `inject/codex-taskboard.user.js` 将自动化请求转发给 Codex 宿主，并最多等待 60 秒。
5. 宿主完成槽位自动化更新后，面板保存确认状态；后续 Codex 调度为每个激活槽位创建对应会话。

## 修改边界

- 状态刷新固定使用只读 `list`。
- React 面板请求超时改为 60 秒。
- 注入层宿主请求超时改为 60 秒。
- 不调整认领间隔、并发数量、任务选择、Worktree 或当前事项状态。
